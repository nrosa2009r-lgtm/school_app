# 🚀 School app

> Jest to aplikacja dla uczniów szkół do ułatwiena im życia w szkole.
---

## ✨ Funkcje
- 📱 **Responsywny design** – działa świetnie na telefonach i komputerach.
- ⚡ **Szybkie działanie** – zoptymalizowany pod kątem wydajności.
- 🔒 **Bezpieczeństwo** – wbudowana ochrona danych użytkownika.
- 🛠️ **Łatwa konfiguracja** – gotowy do uruchomienia w kilka minut.
- 🐍 **Kod jest pisany tylko w pythonie** - łatwa naprawa będów i proste skalowanie 

---

## 🛠️ Użyte technologie

| Technologia | Zastosowanie | Wersja |
| :--- | :--- | :--- |
| **Python** | Logika aplikacji i backend | `3.11+` |
| **flet** | UI | `3.0` |
| **SQLAlchemy** | Baza danych | `3.x` |
| **FastAPI** | API | `3.x` |
